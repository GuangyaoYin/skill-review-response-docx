# Wiley/JGR Manuscript Format Reference

Use this only when the target journal is Wiley/Journal of Geophysical Research or the user explicitly provides the SciSpace Wiley JGR format link.

- The page identifies the format as a Wiley `Journal of Geophysical Research` template and lists an author-year citation style.
- Treat SciSpace as a helpful formatting/template reference, not as the final authority. If a submission depends on exact compliance, verify against the journal or publisher's official author guidelines before final delivery.

## How To Apply

- Use this reference mainly for manuscript/PDF-style visual formatting, not for the Response to Reviewers letter unless the user asks to match the same style.
- Preserve a sober academic layout: conventional margins, readable serif body text, clear section hierarchy, and uncluttered figure/table placement.
- Keep author, title, abstract, main text, acknowledgments, references, figure captions, and tables in a journal-manuscript structure when producing a clean manuscript or PDF-style preview.
- Use author-year citation conventions when the manuscript or journal target calls for JGR/Wiley formatting.
- Do not force this layout onto a marked revision manuscript if it would obscure red changes or review visibility.

## Guardrails

- Do not invent journal requirements from memory. If exact details are needed, inspect the current official Wiley/AGU instructions or ask the user to provide them.
- Do not cite or rely on the template page as proof that the paper satisfies submission requirements.
- Keep the user's original manuscript formatting unless the user asks for a reformatting pass or the target journal requires it.
